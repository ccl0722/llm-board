价格与使用

API 价格

缓存命中价、峰谷时段、促销期与第三方渠道折扣都写在「计价方式」列 —— 标价相同不代表账单相同。

纵轴 = Artificial Analysis 智能指数 v4.3；横轴 = 跑完一道智能指数任务的加权平均实测成本（美元，对数刻度）—— 它把推理 token 消耗量与缓存命中都算进去了，比标价更接近真实账单。只画出两项都有数据的模型，缺一项即不参与。注意这是「跑评测任务」的成本，不等于你自己业务的单次调用成本。
